# Article RAG

RAG (Retrieval-Augmented Generation) сервис для работы с научными статьями.

Позволяет загружать PDF документы, сохранять их в векторную БД (Qdrant), и задавать вопросы и получать ответы через LLM на основе представленных данных.

Система построена модульно и позволяет гибко настраивать компоненты (LLM, эмбеддинги, чанкинг, ретривер) через конфигурацию.

---

## Основной функционал

### Ingest (загрузка документа)

- принимает PDF файл
- извлекает текст
- разбивает на чанки
- считает эмбеддинги
- сохраняет в Qdrant
- защита от дублей (через hash к doc_id)

### Query (вопрос к системе)

- принимает текстовый запрос
- ищет релевантные чанки (косинусное сходство)
- строит prompt
- отправляет в LLM
- возвращает ответ

## Архитектура

### `api/`
- FastAPI роуты
- схемы запросов/ответов

### `service/`
- оркестрация всей логики

### `rag/`

#### `chunking/`
- логика разбиения текста

#### `embeddings/`
- построение эмбеддингов

#### `retrieval/`
- поиск релевантных чанков

#### `prompting/`
- сборка промпта для LLM

#### `llm/`
- обращение к LLM

### `db/`
- работа с Qdrant

### `utils/`
- PDF reader (извлечение текста)

### `config/`
- конфигурация приложения через `config.json` (пример: `config_example.json`)

### `data/`
- хранение данных Qdrant (локально)
